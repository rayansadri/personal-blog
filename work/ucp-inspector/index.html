UCP INSPECTOR

Trace agentic commerce from your terminal.

A local-first debugging tool. Inspect the decision that stopped checkout, then replay it safely.

The problem

A shopping request can pass product selection and still fail at delivery. A final error alone doesn't explain which constraint blocked the flow.

What I built

A TypeScript CLI with profile discovery, structured traces, step inspection, offline replay and trace comparison. This browser demo runs the same fixture engine.

Product decisions

Keep traces local. Separate protocol-shaped fixture operations from local orchestration. Make failure inspectable, and make replay incapable of placing an order.

Technical approach

TypeScript, Node.js, Commander, Ink / React, Zod and local JSON persistence. The browser adapter shares the deterministic execution engine, without a backend or API keys.

Architecture

Configured endpoint → read-only discovery → validate → optional record
Fixture → shared engine → trace → CLI / browser inspector
Trace → offline replay → diff

Boundaries & trade-offs

Discovery supports a documented subset of UCP 2026-01-23 profiles. Checkout operations here are simulated, not live merchant API calls. No Shopify adapter, payments, third-party interception or production results are claimed.
