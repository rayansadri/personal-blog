# Rayan Sadri Website

Static personal site.

## Deploy with GitHub Pages

Push this repository to GitHub, then in GitHub:

1. Go to `Settings` -> `Pages`.
2. Set source to `Deploy from a branch`.
3. Choose `main` and `/root`.
4. Save.

GitHub Pages should publish:

`https://<username>.github.io/<repo>/`

Only the real site files need to be committed:

- `index.html`
- `assets/carez-ai-ui.png`
- `.nojekyll`
- `README.md`

The Webflow embed files were experiments and should not be used.
